# 서울 주요 상권 생활인구 패턴 분석

서울시 주요 상권의 생활인구·방문인구 데이터를 활용해 상권의 시간대별 유동 패턴, 내국인/외국인 구성, 방문 중심성, 면적 대비 밀도를 분석하고 상권 유형별 활성화 전략을 도출한 프로젝트입니다.

## 프로젝트 목표

상권 활성화 전략은 직관이나 경험만으로 수립하기 어렵습니다. 이 프로젝트는 서울시 주요 상권 데이터를 기반으로 상권별 실제 인구 흐름을 분석하여 다음 질문에 답하는 것을 목표로 합니다.

- 어떤 상권이 주간 업무형 상권인가?
- 어떤 상권이 야간에도 활성화되는 유흥·여가형 상권인가?
- 단기 외국인 비중이 높은 관광형 상권은 어디인가?
- 주거 기반 수요가 안정적인 생활 밀착형 상권은 어디인가?
- 상권 유형별로 어떤 정책·마케팅 전략이 적합한가?

## 활용 데이터

분석에는 서울시 주요 상권 생활인구 데이터 4종을 사용했습니다.

| 데이터 | 의미 |
| --- | --- |
| `TOTL` | 전체 인구 |
| `NAOR` | 내국인 |
| `STPRD_FRNR` | 단기 체류 외국인 |
| `LOPRD_FRNR` | 장기 체류 외국인 |

데이터는 상권 단위로 구성되어 있으며, 각 상권에 대해 00시부터 23시까지 시간대별 생활인구와 방문인구 정보를 제공합니다.

### 기본 구조

- 기준 연월: `202510`
- 분석 상권 수: 172개
- 자치구 수: 25개
- 병합 키: `TRDAR_NO`, `DATA_STRD_YM`
- 최종 산출 데이터: `merged_features_v3.csv`

## 분석 절차

### 1. 데이터 구조 파악

4개 인구 유형 파일의 컬럼 구조, 키, 중복 여부, 결측치, 시간대별 컬럼 패턴을 확인했습니다.

- 각 파일은 172개 상권을 포함합니다.
- 시간대별 생활인구 컬럼 24개, 방문인구 컬럼 24개가 존재합니다.
- 결측치는 발견되지 않았습니다.
- 일부 외국인 인구 값이 0 또는 매우 작은 값으로 나타나지만, 이는 실제 외국인 유입이 적은 상권의 특성으로 보고 제거하지 않았습니다.

### 2. 데이터 전처리

전체 인구 데이터(`TOTL`)를 기준으로 내국인, 단기 외국인, 장기 외국인 데이터를 left join 방식으로 병합했습니다.

전처리 결과:

- 병합 후 key 중복 없음
- 분석에 치명적인 결측치 없음
- 상권 면적과 인구 변수는 우측 꼬리가 긴 분포를 보임
- 대형 핵심 상권과 다수의 중소 생활형 상권이 공존하는 구조 확인

### 3. 파생변수 생성

상권 유형화를 위해 다음과 같은 파생변수를 생성했습니다.

- `peak_hour_col`: 상권별 생활인구 피크 시간대
- `day_ratio`: 주간 집중도
- `night_ratio`: 야간 집중도
- `foreigner_ratio`: 외국인 비중
- `short_foreigner_ratio`: 단기 외국인 비중
- `visitor_ratio`: 방문 중심성
- `population_density`: 면적 대비 인구 밀도
- `visit_intensity`: 면적 대비 방문 강도
- `transition_ratio`: 전환 시간대 인구 비중

### 4. 탐색적 데이터 분석

EDA에서는 다음 항목을 중심으로 상권 특성을 확인했습니다.

- 서울 전체 상권의 평균 시간대별 생활인구 패턴
- 단기 외국인 비중 상위 상권
- 야간 집중 상권
- 방문 비중과 방문 강도
- 주간/야간 비율과 외국인 비중 간 관계
- 주요 파생변수 간 상관관계

### 5. 상권 유형화

K-Means 군집화를 통해 서울 상권을 4개 유형으로 분류하는 방향을 설계했습니다.

사용 변수:

- `visitor_ratio`
- `short_foreigner_ratio`
- `visit_intensity`
- `day_ratio`

Elbow Method를 기준으로 `k=4`를 선택했으며, 목표 유형은 다음과 같습니다.

| 유형 | 설명 | 예시 상권 |
| --- | --- | --- |
| 업무 집중형 | 주간 인구와 방문 비중이 높은 업무 중심 상권 | 시청, 종각, 여의도, 강남권 |
| 야간 유흥형 | 저녁·심야 시간대 인구 유지가 강한 상권 | 홍대, 건대, 신림, 사당 |
| 글로벌 관광형 | 단기 외국인 비중이 높은 관광·쇼핑 상권 | 명동, 을지로, 회현, 동대문, 이태원 |
| 주거 밀착형 | 주거 기반 수요가 안정적인 생활 상권 | 목동, 노원, 송파 등 |

## 주요 분석 결과

### 시간대별 패턴

서울 전체 상권의 평균 생활인구는 오후 3시에 가장 높고, 새벽 4시에 가장 낮게 나타났습니다. 이는 오전 이후 증가해 오후에 정점을 찍고 야간에 감소하는 전형적인 도시형 활동 패턴입니다.

### 관광형 상권

단기 외국인 및 외국인 비중이 높은 상권은 명동, 을지로, 회현, 동대문, 홍대, 신촌, 이태원 등 관광·쇼핑·문화 상권에 집중되어 있습니다.

외국인 비중 상위 상권 예시:

1. 명동역6번 출구
2. 서울소공동우체국
3. 서울구로4동우체국
4. 을지로3가역8번 출구
5. 홍대입구역9번 출구
6. 회현역5번 출구
7. 동대문역사문화공원역14번 출구
8. 신촌역3번 출구
9. 홍대입구역3번 출구
10. 이태원역2번 출구

### 야간 집중 상권

야간 인구 비중이 높은 상권은 방이, 건대입구, 신림, 사당, 홍대, 혜화 등으로 나타났습니다. 이들은 유흥, 여가, 대학가, 역세권 특성이 강하며 야간 경제 활성화 가능성이 높은 지역입니다.

### 주간 집중 상권

주간 인구 비중이 높은 상권은 시청, 회현, 종각, 고속터미널, 봉은사, 을지로입구 등으로 확인되었습니다. 업무·도심·교통 거점 성격이 강한 상권입니다.

### 변수 간 관계

EDA에서 확인한 주요 관계는 다음과 같습니다.

- `day_ratio`와 `visitor_ratio`는 양의 관계를 보입니다.
- `night_ratio`와 `visitor_ratio`는 음의 관계를 보입니다.
- `visitor_ratio`와 `short_foreigner_ratio`는 양의 관계를 보입니다.
- `visit_intensity`와 `population_density`는 매우 강한 상관을 보여 사실상 유사한 성격의 지표로 해석됩니다.

## 유형별 전략 제안

### 업무 집중형

- 점심시간 회전율 극대화
- 모바일 선주문, 빠른 테이크아웃 시스템 도입
- 17~19시 퇴근길 직장인 대상 프로모션
- 오피스 근무 패턴에 맞춘 시간대별 마케팅

### 야간 유흥형

- 심야 경제 활성화
- 야간 영업 인센티브
- 안전 귀가 인프라 확충
- 야간 교통, 문화 행사, 지역 축제 연계

### 글로벌 관광형

- 다국어 안내 강화
- 해외 간편결제 도입
- 외국인 환급 서비스 개선
- 관광객 맞춤형 상품과 동선 설계

### 주거 밀착형

- 지역 주민 대상 멤버십
- 가족·키즈·펫 친화 시설 확충
- 지역 커뮤니티 연계 마케팅
- 안정적 재방문을 유도하는 관계 중심 전략

## 한계 및 개선 방향

현재 분석은 생활인구와 방문인구를 기반으로 상권의 유입·체류 패턴을 분석한 결과입니다. 실제 소비 규모, 매출, 카드 사용 데이터와는 차이가 있을 수 있습니다.

향후 보완하면 좋은 항목은 다음과 같습니다.

- 카드 매출 데이터와 결합해 실제 소비 효과 검증
- K-Means 결과에 대한 Silhouette Score 제시
- Elbow Method와 Silhouette Score를 함께 활용한 군집 수 선택 근거 강화
- 업무형과 유흥형의 야간 활성 비율 차이에 대한 t-test
- 관광형 상권의 단기 외국인 비중 차이에 대한 ANOVA
- 동 단위 또는 블록 단위의 더 세밀한 공간 분석
- 예비 창업자를 위한 AI 기반 상권 추천 모델 고도화

## 결론

서울 주요 상권은 시간대, 방문 목적, 외국인 비중, 면적 대비 밀도에 따라 서로 다른 특성을 보입니다. 따라서 모든 상권에 동일한 활성화 전략을 적용하기보다, 업무형·야간형·관광형·주거형 등 유형별로 차별화된 정책과 비즈니스 전략을 설계하는 것이 효과적입니다.
